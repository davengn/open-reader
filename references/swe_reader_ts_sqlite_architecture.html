SWE reader app — TypeScript + SQLite architecture: stack layers, folder structure, schema, and feature modules

Stack layers
Frontend — Next.js 15 App Router
React server + client components, shadcn/ui, Tailwind. pdf.js renders PDFs, epub.js renders EPUBs — both run fully in-browser.
next pdfjs-dist epubjs shadcn/ui tailwindcss lucide-react
Backend — Next.js API Routes + Server Actions
No separate server process. API routes handle file uploads, streaming AI responses (SSE). Server actions handle mutations — save note, update progress, toggle highlight.
next/server zod formidable pdf-parse epub2
ORM — Drizzle + better-sqlite3
TypeScript-first schema, type-safe queries, zero runtime overhead. Drizzle Kit handles migrations. SQLite FTS5 (built-in) for full-text book search — no vector DB needed.
drizzle-orm better-sqlite3 drizzle-kit SQLite FTS5
Storage — reader.db + /books filesystem
One SQLite file for all metadata, highlights, notes, flashcards, and book text chunks. Raw PDF/EPUB files stay on disk in /books. No S3, no cloud — just files.
reader.db /books/*.pdf /books/*.epub
AI — Anthropic SDK (Claude)
FTS5 retrieves relevant book chunks → stuffed into Claude's context. Streaming SSE response for chat. Batch generate flashcards from highlights. Chapter summaries on demand.
@anthropic-ai/sdk claude-sonnet-4-5 FTS5 retrieval

Feature modules to build
PDF + EPUB reader
pdf.js renders pages. epub.js handles reflowable text. Both expose text selection for highlighting.
Highlights + notes
Select text → pick color → save via server action. Notes attach to highlights or stand-alone per page.
Full-text search (FTS5)
SQLite FTS5 virtual table indexes all book text at upload time. Zero-latency search across your whole library.
Chat with book (RAG)
FTS5 retrieves top chunks for the query → sent as context to Claude → streams response back via SSE.
Flashcards (SM-2)
Claude generates front/back from a highlight. SM-2 algorithm (pure TS, 20 lines) schedules next review.
Reading progress
Debounced server action saves page / epub CFI on scroll. Resume exactly where you left off.
